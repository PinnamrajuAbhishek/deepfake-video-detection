# Deepfake Video Detection

Multimodal deepfake detection pipeline combining facial micro-expression analysis and breathing-based audio analysis for robust fake video identification.

---

## Overview

This project focuses on detecting manipulated videos using physiological and behavioral cues extracted from both facial movements and audio signals.

The system combines:
- Duchenne marker analysis
- Facial co-activation score analysis
- Breathing-based audio analysis
- Cross-dataset evaluation workflows

---

## Features

- Multimodal audio-video analysis
- Deepfake detection using physiological signals
- Cross-dataset robustness evaluation
- Synchronized preprocessing pipelines
- Feature extraction and fusion workflows

---

## Tech Stack

- Python
- PyTorch
- OpenCV
- NumPy
- Librosa
- Scikit-learn

---

## Dataset

Experiments were conducted using benchmark deepfake datasets involving both real and manipulated video samples.

## Results

- Achieved 93% accuracy across benchmark datasets
- Improved robustness through cross-dataset validation
- Evaluated performance against unseen manipulations and domain shifts
